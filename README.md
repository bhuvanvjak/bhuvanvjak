A computer vision experiment using **CLIP as a frozen feature extractor** with a custom classifier.

The interesting part wasn't just training the model — it was understanding where it failed under different lighting, pose, and image conditions.

`PyTorch` `TensorFlow/Keras` `OpenAI CLIP`
